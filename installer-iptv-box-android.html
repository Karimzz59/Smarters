Installer IPTV Smarters Pro sur une box Android

Les box Android (Xiaomi Mi Box, box TV Android génériques, boîtiers vendus avec une télécommande à pavé) sont une solution économique pour transformer n'importe quel téléviseur en TV connectée. Il existe deux familles : les box sous Android TV officiel (avec Play Store TV) et les box sous Android « classique », dont l'interface ressemble à celle d'une tablette. IPTV Smarters Pro s'installe sur les deux.

Ce qu'il vous faut

  • Une box Android reliée au téléviseur en HDMI et connectée à internet (Ethernet recommandé).
  • Une télécommande ou, idéalement, une souris sans fil pour les box Android classiques.
  • Vos identifiants Xtream Codes.

Installer IPTV Smarters Pro sur box Android

Si votre box fonctionne sous Android TV (Mi Box notamment), suivez notre guide IPTV Smarters Pro sur Android TV. Pour une box Android classique :

  1. Ouvrez le navigateur de la box (Chrome ou le navigateur intégré).
  2. Rendez-vous sur le site officiel iptvsmarters.com et téléchargez la version Android de l'application.
  3. Au premier téléchargement, Android demande d'autoriser l'installation d'applications depuis le navigateur : acceptez dans la fenêtre qui s'ouvre (ou via Paramètres > Sécurité > Sources inconnues sur les anciennes versions).
  4. Ouvrez le gestionnaire de fichiers (dossier « Téléchargements ») et touchez le fichier APK pour l'installer.
  5. Après l'installation, supprimez le fichier APK pour libérer de l'espace.
  6. Lancez IPTV Smarters Pro depuis la liste des applications.

Sécurité : téléchargez uniquement l'APK depuis le site officiel de l'éditeur (iptvsmarters.com). Les APK « modifiés », « premium débloqués » ou proposés sur des sites inconnus peuvent contenir des publicités intrusives ou des logiciels malveillants. Voir notre guide IPTV Smarters Pro APK : télécharger en sécurité.

Connecter votre abonnement dans IPTV Smarters Pro

Une fois l'application installée, la connexion est identique sur tous les appareils. Utilisez de préférence la méthode Xtream Codes : le guide TV (EPG), les films et les séries se configurent automatiquement.

  1. Ouvrez l'application et acceptez les conditions d'utilisation au premier lancement.
  2. Choisissez « Login with Xtream Codes API » (parfois « Ajouter un utilisateur » puis « Xtream Codes »).
  3. Dans Any Name, tapez un nom libre (par exemple « Salon »).
  4. Saisissez le nom d'utilisateur, le mot de passe et l'URL du serveur reçus avec votre abonnement, en respectant majuscules, minuscules et le préfixe http://.
  5. Validez avec « Add User » : l'application télécharge les chaînes, les films, les séries et le guide TV. Le premier chargement peut prendre une à deux minutes.

Vous n'avez qu'un lien M3U ? Choisissez « Load Your Playlist or File/URL » et collez le lien. Cela fonctionne, mais le guide TV et le replay sont moins complets qu'avec Xtream Codes. Plus de détails dans notre guide configurer un lien M3U.

Conseils pour une box Android fluide

  • Ethernet plutôt que Wi-Fi : beaucoup de box d'entrée de gamme ont une puce Wi-Fi faible. Le câble est le meilleur remède aux coupures.
  • Résolution de sortie : réglez la box sur la résolution native du téléviseur (1080p ou 4K) dans Paramètres > Affichage.
  • Mises à jour : une version d'Android trop ancienne (avant Android 7) peut empêcher l'installation des versions récentes de l'application.
  • Box « préconfigurées » : méfiez-vous des box vendues avec des applications IPTV déjà installées : elles contiennent souvent des versions modifiées. Réinitialisez-les et installez l'application officielle.

Problèmes fréquents et solutions

« Il y a eu un problème lors de l'analyse du paquet »

La version de l'application est trop récente pour l'Android de votre box, ou le fichier est incomplet. Vérifiez la version d'Android dans Paramètres > À propos et retéléchargez le fichier.

La télécommande ne permet pas de cliquer dans l'application

Certaines box classiques sont pensées pour le tactile : une souris sans fil USB règle le problème en quelques secondes.

« Invalid details » ou « Authorization failed »

Les identifiants sont mal saisis (espace en trop, majuscule oubliée, URL sans http://) ou l'abonnement a expiré. Ressaisissez-les lentement ; si l'erreur persiste, écrivez-nous.

Les chaînes se chargent mais ne se lancent pas

Changez le lecteur dans Paramètres > Player Selection (lecteur interne ou VLC), puis relancez l'application.

Coupures ou image qui se fige

Privilégiez un câble Ethernet ou un Wi-Fi 5 GHz, redémarrez la box internet, et baissez la qualité (HD au lieu de 4K) si votre débit est inférieur à 25 Mbps.

Guide TV (EPG) vide

Allez dans Paramètres > EPG et lancez une mise à jour, ou supprimez puis ajoutez de nouveau le profil Xtream Codes.

Questions fréquentes

Quelle box Android choisir pour IPTV Smarters Pro ?

Une box sous Android TV officiel (Xiaomi Mi Box, Google TV Streamer, Nvidia Shield) offre la meilleure stabilité et des mises à jour de sécurité. Les box génériques fonctionnent mais sont plus inégales.

Box Android ou Firestick ?

Le Firestick est plus simple et bien suivi par Amazon. Une box Android offre souvent plus de ports (USB, Ethernet intégré). Pour l'IPTV, un modèle récent de l'un ou l'autre fait parfaitement l'affaire.

Dois-je rooter ma box ?

Non, jamais. IPTV Smarters Pro s'installe sans root, et le root affaiblit la sécurité de l'appareil.
