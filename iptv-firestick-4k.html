Installer IPTV Smarters Pro sur Firestick : le guide complet 2026

Le Firestick d'Amazon (Fire TV Stick, 4K, 4K Max, Lite) est l'appareil le plus utilisé avec IPTV Smarters Pro. Il y a une subtilité : l'application n'est pas proposée dans l'Amazon Appstore. Il faut donc l'installer à partir de son fichier APK, grâce à l'application gratuite Downloader. Comptez 10 minutes, sans aucune compétence technique.

Ce qu'il vous faut

  • Un Amazon Fire TV Stick (toutes générations) ou un Fire TV Cube, connecté à internet.
  • La télécommande et environ 100 Mo d'espace libre.
  • Votre abonnement IPTV : nom d'utilisateur, mot de passe et URL du serveur (Xtream Codes).

Installer IPTV Smarters Pro sur Firestick, étape par étape

1. Activer les options pour les développeurs

Sur les Firestick récents, ce menu est masqué. Allez dans Paramètres > Ma Fire TV > À propos, placez-vous sur le nom de votre appareil (par exemple « Fire TV Stick 4K ») et appuyez 7 fois sur le bouton central. Le message « Vous êtes maintenant développeur » s'affiche.

2. Installer Downloader puis IPTV Smarters Pro

  1. Depuis l'accueil, ouvrez la Recherche, tapez Downloader et installez l'application (icône orange, éditeur AFTVnews).
  2. Revenez dans Paramètres > Ma Fire TV > Options pour les développeurs > Installer des applications inconnues et activez Downloader.
  3. Ouvrez Downloader, autorisez l'accès aux fichiers, puis sélectionnez le champ d'adresse sur l'écran « Home ».
  4. Saisissez l'adresse de téléchargement Android du site officiel iptvsmarters.com (ou le code Downloader qui y correspond, voir ci-dessous) et validez avec Go.
  5. Une fois le fichier téléchargé, choisissez Installer, puis Terminé.
  6. Downloader propose de supprimer le fichier APK : acceptez (Delete), l'application reste installée et vous libérez de l'espace.
  7. Retrouvez IPTV Smarters Pro dans Vos applications ; maintenez le bouton menu pour la déplacer sur l'écran d'accueil.

Connecter votre abonnement dans IPTV Smarters Pro

Une fois l'application installée, la connexion est identique sur tous les appareils. Utilisez de préférence la méthode Xtream Codes : le guide TV (EPG), les films et les séries se configurent automatiquement.

  1. Ouvrez l'application et acceptez les conditions d'utilisation au premier lancement.
  2. Choisissez « Login with Xtream Codes API » (parfois « Ajouter un utilisateur » puis « Xtream Codes »).
  3. Dans Any Name, tapez un nom libre (par exemple « Salon »).
  4. Saisissez le nom d'utilisateur, le mot de passe et l'URL du serveur reçus avec votre abonnement, en respectant majuscules, minuscules et le préfixe http://.
  5. Validez avec « Add User » : l'application télécharge les chaînes, les films, les séries et le guide TV. Le premier chargement peut prendre une à deux minutes.

Vous n'avez qu'un lien M3U ? Choisissez « Load Your Playlist or File/URL » et collez le lien. Cela fonctionne, mais le guide TV et le replay sont moins complets qu'avec Xtream Codes. Plus de détails dans notre guide configurer un lien M3U.

Un code Downloader est un raccourci numérique : au lieu de taper une longue adresse avec la télécommande, vous saisissez quelques chiffres et Downloader ouvre le lien associé. Ces codes sont créés par n'importe qui, via le service raccourcisseur d'AFTVnews : ils ne sont pas délivrés par l'éditeur d'IPTV Smarters.

Conséquence pratique : un code trouvé sur un forum peut pointer vers une ancienne version, vers une copie modifiée de l'application, ou cesser de fonctionner du jour au lendemain. Deux règles simples :

  • Si Downloader affiche une page web, vérifiez que vous êtes bien sur iptvsmarters.com avant de télécharger.

Bien choisir son Firestick pour l'IPTV

Tous les modèles fonctionnent, mais l'expérience diffère. Le Fire TV Stick 4K Max est le plus fluide pour le zapping et la 4K, grâce à son processeur plus rapide et au Wi-Fi 6/6E. Le modèle Lite suffit pour la HD. Si votre box internet est loin de la TV, un adaptateur Ethernet pour Firestick (environ 15 €) supprime la plupart des coupures pendant les matchs.

Problèmes fréquents et solutions

Downloader n'apparaît pas dans « Installer des applications inconnues »

Vérifiez que les options pour les développeurs sont bien activées (7 appuis sur le nom de l'appareil), puis redémarrez le Firestick depuis Paramètres > Ma Fire TV > Redémarrer.

« Échec de l'analyse du paquet » ou installation impossible

Le fichier est incomplet ou ne correspond pas à votre appareil. Supprimez-le dans Downloader (onglet Files) et relancez le téléchargement depuis le site officiel.

Firestick lent ou qui chauffe

Videz le cache : Paramètres > Applications > Gérer les applications installées > IPTV Smarters Pro > Vider le cache. Désinstallez aussi les applications inutilisées.

« Invalid details » ou « Authorization failed »

Les identifiants sont mal saisis (espace en trop, majuscule oubliée, URL sans http://) ou l'abonnement a expiré. Ressaisissez-les lentement ; si l'erreur persiste, écrivez-nous.

Les chaînes se chargent mais ne se lancent pas

Changez le lecteur dans Paramètres > Player Selection (lecteur interne ou VLC), puis relancez l'application.

Coupures ou image qui se fige

Privilégiez un câble Ethernet ou un Wi-Fi 5 GHz, redémarrez la box internet, et baissez la qualité (HD au lieu de 4K) si votre débit est inférieur à 25 Mbps.

Guide TV (EPG) vide

Allez dans Paramètres > EPG et lancez une mise à jour, ou supprimez puis ajoutez de nouveau le profil Xtream Codes.

Questions fréquentes

IPTV Smarters Pro est-il disponible sur l'Amazon Appstore ?

Non, l'application n'est pas proposée dans l'Amazon Appstore. On l'installe à partir de son APK avec l'application Downloader, qui, elle, est disponible dans l'Appstore.

Quel est le code Downloader pour IPTV Smarters Pro ?

Les codes qui circulent sont créés par des tiers et changent régulièrement. Le plus sûr est de saisir l'adresse du site officiel iptvsmarters.com, ou d'utiliser le lien vérifié que nous envoyons à nos abonnés avec leurs identifiants.

Installer une application hors Appstore est-il risqué pour le Firestick ?

Non, si l'APK provient du site officiel de l'éditeur. Le risque vient des versions modifiées trouvées sur des sites inconnus. Vous pouvez désactiver à nouveau les sources inconnues après l'installation.

Faut-il un VPN sur Firestick ?

Ce n'est pas nécessaire pour faire fonctionner IPTV Smarters Pro. Un VPN peut ralentir la connexion ; en cas de coupures, commencez plutôt par vérifier votre Wi-Fi.

Pourquoi l'image est-elle floue sur mon Firestick 4K ?

La qualité dépend du flux choisi et de votre débit. Sélectionnez la version 4K ou FHD de la chaîne quand elle existe, et vérifiez que votre connexion atteint environ 25 Mbps stables pour la 4K.
